# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in pi2pi (smart contracts, backend, frontend, or keeper), please **do not open a public GitHub issue** describing it.

Instead, report it privately via:

- Email: hello@pi2pi.io
- X/Twitter: [@dim_ul](https://x.com/dim_ul)

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce, if applicable
- Any relevant contract addresses, transaction hashes, or code references

We'll acknowledge your report and follow up as we investigate. There is currently no formal bug bounty program.
