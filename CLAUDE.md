## Project Overview

**pi2pi.io** — P2P rental platform with smart-contract escrow for deposits. USDC on Arc Testnet. Circle Programmable Wallets (WebAuthn/passkeys, ERC-4337). No commissions. Yield spread on stablecoins via ERC-4626 adapters (Aave, Morpho).

## Safety Rules

1. **No edits to backend/auth/wallet/contracts/transaction logic** unless explicitly requested.
2. **No mixed tasks in one diff.** Each task gets its own commit.
3. **"Inspection only"** = read and report, no edits.
4. **"Patch" / "fix"** = edit only, do not commit unless told.
5. **Commit only after explicit approval** ("делай", "да", "commit").
6. **Deploy only after explicit approval.** Never auto-deploy.
7. **Never stage `arc/dist/`** — build artifacts are regenerated by Dockerfile.
8. **If unexpected files appear in diff, stop and report** before committing.
9. **Always create a new commit** before every deploy (rollback safety).
10. **Check `git diff --name-only` before every commit** — report what will be committed.

## Build & Deploy

```bash
# Frontend build (required after any arc/src change)
cd arc && npm run build

# Deploy (from project root, after commit)
flyctl deploy

# Pre-deploy checklist:
# 1. git diff --name-only -- arc/src server-arc.js auth.js  (expect: no diffs)
# 2. git log --oneline -3  (verify HEAD is the right commit)
# 3. git status --short  (only dist artifacts and untracked files)
```

## i18n Rules

- **EN is the source language** for all UI copy.
- Active languages: `en`, `ru`, `ka`, `vi`, `es`, `pt`, `th`, `uk`.
- When adding/changing a UI string: update all 8 `arc/src/i18n/*.js` files.
- Legal agreement text lives in `arc/src/lease-text-*.js` (separate from UI i18n).
- Do not leave raw i18n keys visible in UI (e.g. `btn.foo` showing as button text).
- Log new keys in `pitch/i18n-changelog.md`.

## Agreement / Print Document

- `PrintModal.jsx` = final agreement modal (fetches on-chain data, wraps AgreementDocument).
- `AgreementDocument.jsx` = pure renderer, no hooks, no data fetching. Receives normalized data.
- Pre-sign agreement preview reuses `AgreementDocument` with form data (agreementId=null).
- Do not create divergent document layouts — one renderer for both pre-sign and final.
- Appendix A uses `/api/ipfs/decrypt/` for encrypted docs.
- Appendix B uses `/api/ipfs/file/` for plain property photos.
- Appendix C uses `/api/ipfs/decrypt/` for encrypted inventory photos.

## Smart Contract — RentalEscrow.sol

State machine: `Created → AwaitingLandlordDep/AwaitingTenantDep → Active → CheckoutProposed/EarlyTermProposed → DamageClaimed → DisputeOpen → Settled`

Deposit model (symmetric "equal stakes"):
- Commitment Deposit (tenant) = 1× monthly rent
- Hosting Deposit (landlord) = 1× monthly rent
- Property Security Deposit (tenant, optional) = 0–3× monthly rent

Yield: deposits via ERC-4626 adapters. Split: 70% to parties, 30% to protocol treasury.

Network: Arc Testnet (chainId 5042002). Token: USDC.

## Keeper — keeper/enforcer.ts

Enforcement bot on Fly.io monitoring RentalEscrow deadlines. Four paths:
- `Active` + `isRentOverdue()` → `flagRentMissed()`
- `DamageClaimed` + tenant silent → `executeExpiredClaim()`
- `DamageClaimed` + landlord didn't post bond → `expireDamageClaim()`
- `DisputeOpen` + `isFreezeExpired()` → `releaseFrozenFunds()`
